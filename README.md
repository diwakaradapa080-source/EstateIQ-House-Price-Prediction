# EstateIQ — House Price Prediction & Model Insights

A portfolio-ready machine-learning web application that estimates a property's practice-dataset price from six attributes. Built with Python, Flask, Pandas and Scikit-learn.

> **Dataset transparency:** The included `house_prices.csv` contains synthetic/generated practice data. This project demonstrates a complete ML workflow; its outputs are not reliable market valuations. Do not present its test metrics as evidence of real-estate market accuracy.

## What is included

- Responsive multi-page interface: Predictor, Model Insights and Project Overview
- Instant house-price estimates from six validated inputs
- Comparison of Linear Regression and Random Forest Regression
- Model evaluation with MAE, RMSE and R² on a held-out test split
- Automatic selection and persistence of the best test-set model
- Recent prediction history for the current browser session
- JSON prediction endpoint (`POST /api/predict`)
- Health-check endpoint (`GET /health`)
- Clear explanation of the training pipeline and project technologies

## Tech stack

Python 3 · Flask · Pandas · NumPy · Scikit-learn · Joblib · HTML · CSS

## Run on Windows (VS Code)

1. Extract the ZIP file.
2. Open the extracted `House_Price_Prediction_Pro` folder in VS Code.
3. Open Terminal → New Terminal.
4. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   ```

5. Install the dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

6. Train and compare the models:

   ```powershell
   python train_model.py
   ```

   This creates the `models/` folder and `model_evaluation.csv`.

7. Start the Flask application:

   ```powershell
   python app.py
   ```

8. Open **http://127.0.0.1:5000** in your browser.

## Input features

| Feature | Meaning |
|---|---|
| `area_sqft` | Built-up area in square feet |
| `bedrooms` | Number of bedrooms |
| `bathrooms` | Number of bathrooms |
| `age_years` | Property age in years |
| `location_score` | Illustrative location score from 1 to 10 |
| `parking_spaces` | Number of parking spaces |

## API example

`POST /api/predict`

Request JSON:

```json
{
  "area_sqft": 1200,
  "bedrooms": 2,
  "bathrooms": 2,
  "age_years": 5,
  "location_score": 7,
  "parking_spaces": 1
}
```

Successful response:

```json
{
  "success": true,
  "predicted_price_inr": 0,
  "model": "Linear Regression"
}
```

The numeric value above is only a response-shape example; the actual value is generated by the trained model.

Health check: `GET /health`

## Model evaluation

The training script uses an 80:20 train/test split (`random_state=42`). It compares:
- **MAE:** mean absolute error; lower is better.
- **RMSE:** root mean squared error; lower is better.
- **R²:** coefficient of determination; higher is generally better.

The model with the strongest test-set R² is saved and used by the Flask application. Always review the generated `model_evaluation.csv` after retraining.

## Portfolio presentation tips

Before publishing this project:
1. Replace the synthetic CSV with a trusted, appropriately licensed real-estate dataset.
2. Record the dataset source, collection date, geographic coverage and limitations.
3. Re-train and evaluate on a representative holdout set; consider cross-validation and error analysis.
4. Add tests and document limitations, privacy considerations and deployment steps.
5. Include screenshots and a short demo video in your portfolio.

Never claim that a recruiter-facing demo proves production readiness or real-world valuation accuracy.
